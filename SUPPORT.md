# Getting Help

## I'm stuck on my learning path or a cell project

Start with your **Cell Leader** — that is what they are there for. If they cannot unblock you,
they escalate to the Office of Programs and Curriculum.

You can also open a **Discussion** on the relevant repository so other members can help and the
answer stays searchable for the next person.

## I found a bug in a SLINT Tech project

[Open an issue](https://github.com/SLINT-Tech) on that repository using the **Bug report**
template. Include what you expected, what happened, and how to reproduce it.

## I found a security vulnerability

Do not open an issue. Follow [SECURITY.md](SECURITY.md).

## I want to join SLINT Tech

Apply through [slinttech.org](https://slinttech.org). Applications are reviewed by the Membership
Coordinator within seven (7) business days.
