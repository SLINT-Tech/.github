# `.github` — SLINT Tech organization defaults

This repository holds the files GitHub applies **across every repository** in the
[@SLINT-Tech](https://github.com/SLINT-Tech) organization.

Anything defined here is inherited by a repo that does not define its own copy.

| File | What it does |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The public landing page shown on [github.com/SLINT-Tech](https://github.com/SLINT-Tech) |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Behaviour expected of everyone in our spaces |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to propose changes and get them merged |
| [`GOVERNANCE.md`](GOVERNANCE.md) | How SLINT Tech is structured and how decisions are made |
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability |
| [`SUPPORT.md`](SUPPORT.md) | Where to get help |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) | Default issue forms |
| [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | Default pull request checklist |

## Editing these files

Changes here affect every repository in the organization. Open a pull request rather than
committing to `main` directly, and tag [@SLINT-Tech/leadership](https://github.com/orgs/SLINT-Tech/teams/leadership)
for review.
